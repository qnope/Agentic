## Preparation step

1. List `.claude/skills/` and `skills/` in the project root (your working directory; use `ls -a`, `.claude` is hidden). If an existing skill already does the job, it means you want to improve it. Go to RED step directly
2. Can you state in one sentence what the skill does?
   - **No** (e.g. "a skill for testing": testing what, how?): ask your partner using the Question UI, and stop. Do not write the skill until you have a clear description.
   - **Yes**: do not ask. Choose sensible defaults for the trigger and the output, list them as "Assumptions" in the final report, and continue.
3. Propose and discuss with your human partner which scenarios tests (see scenario-template.md) to write.

Skill name: kebab-case. An existing skill is changed where it already is.
